# SkillIssue

React web version of the SkillIssue ancillary training tracker concept.

## What is included

- Brand identity panel with logo mark, palette, buttons, badges, and typography
- Desktop dashboard with sidebar navigation, compliance stats, due-soon training, and announcements
- Responsive mobile app previews for dashboard and training progress
- Training tracking table, user progress view, reports, contact, and admin settings panels

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
